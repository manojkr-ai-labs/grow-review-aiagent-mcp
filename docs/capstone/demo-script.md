# Demo script

About two minutes. Speak these steps in order. The video is recorded by a person after this script. This file is not the video.

## 1. Weekly pulse to its gate

Open Weekly Pulse. Show the note, the gate list, and the explainer under the pulse. Stop when the gates are on screen. Do not start a second pipeline.

Say: "The Groww scheme page supplied the fact, the review theme supplied the count, and the question log supplied the repeated question."

## 2. One question through the response loop

Open Queue and open one covered case. Show the reply, the Groww link, and the last-checked date. If the case is not covered, show the pages searched instead of a claim.

Say: "The model is forbidden to continue past a missing passage, a personal-data block, or an advice request, and the screen shows not covered or the refusal."

## 3. One reviewer rejection

Open a pending case, choose Reject, and return to the queue. The case is still listed as rejected. The explainer file is unchanged.

## 4. One approval of the hash on screen

Open the other case's approval page. Read the content hash aloud. Approve that hash. Point at the sentence that Gmail send will not be called. Do not approve a different hash, and do not publish a hash that is not on the screen.

Say: "The approval gate stopped the write, and it was bound to the hash on this screen."

## 5. One evaluation row

Open `docs/capstone/eval.md`. Read the date, the command `python -m pytest tests/capstone -q`, and one row. E1, E2, and E3 were pass on 2026-11-11.

Say: "That line is drawn there because a review is pattern evidence and a support question is queue evidence, and the hosted MCP server is not exactly-once."
